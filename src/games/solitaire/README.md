# Solitaire (Klondike) - Documentation

## Overview
Classic Klondike Solitaire card game. Build foundation piles from Ace to King by suit while managing tableau piles in descending alternating colors.

## Current Implementation (Level 1 - POC)
- ✅ Standard Klondike rules
- ✅ Draw 3 cards mode
- ✅ 7 tableau piles
- ✅ 4 foundation piles
- ✅ Click-to-select, click-to-move
- ✅ Auto-flip hidden cards
- ✅ Hint system
- ✅ Move counter
- ✅ Win detection
- ✅ Score tracking

## How to Play
1. Click stock to draw 3 cards
2. Click a card to select it
3. Click destination to move
4. Build foundations Ace→King by suit
5. Build tableau King→Ace alternating colors
6. Only Kings can go on empty tableau spaces

## Expansion Levels
**Level 2**: Draw 1 mode, undo/redo
**Level 3**: Auto-complete, statistics
**Level 4**: Timer, scoring system, daily challenges
**Level 5**: Vegas mode, different variants (Spider, FreeCell)
